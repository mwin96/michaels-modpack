# michael's modpack

![michael's modpack](https://github.com/mwin96/michaels-modpack/releases/download/v1.0.3/michaels_modpack_thumbnail-1.0.3.jpg)

**Already on 1.0.3 in Prism?** Close Minecraft and relaunch the pack; it updates automatically.

**Older install?** Close Minecraft and Prism Launcher, [download the update](https://github.com/mwin96/michaels-modpack/releases/download/v1.0.4/michaels-modpack-client-update-1.0.4.zip), extract it, and open **UPDATE MICHAELS MODPACK.cmd**.

**New player?** [Download the Windows starter](https://github.com/mwin96/michaels-modpack/releases/download/v1.0.4/michaels-modpack-1.0.4-windows-easy.zip), extract it, and open **CLICK HERE TO INSTALL AND PLAY.cmd**. Sign in once.

The server is already saved. Future Prism launches update the pack.
